# Chatbot AI tuyen sinh Khoa Marketing DUE

Frontend Next.js App Router cho he thong Chatbot AI ho tro tu van tuyen sinh Khoa Marketing, Truong Dai hoc Kinh te - Dai hoc Da Nang.

## Chay local

```bash
npm install
npm run dev
```

Trang chinh:

- `/`
- `/gioi-thieu`
- `/chatbot-ai`

Neu co backend chatbot, cau hinh `CHATBOT_API_BASE_URL` de route `/api/chatbot-ai` proxy den backend. Khi chua cau hinh backend, API tra ve cau tra loi fallback than thien.
